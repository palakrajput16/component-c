## Overview

This repository contains the Week 1 work for Component C.

The implementation covers the four required statistics:

1. Winner-correct rate
2. Kendall's tau
3. Optimism
4. Power using a paired t-test for c1 vs c2

The analysis is performed for:

- `n_sub = 100`
- `n_sub = 500`

The repository also contains the supplied toy data, the extended generated results, the code used to generate the extended results, and the written hand calculations.

# How to Run the Code

## Requirements

Python 3 is required.

The statistics code uses:

- pandas
- scipy
- numpy

If these packages are not already installed, run:

```bash
pip install pandas scipy numpy
```

---

## Step 1: Generate the Extended Results

The supplied toy data is already present in:

```text
Week_1/data/results.csv
Week_1/data/truth.csv
```

To generate the extended results, open a terminal in the `Week_1/src` folder and run:

```bash
cd Week_1/src
python generate_results.py
```

This generates:

```text
Week_1/data/results_extended.csv
```

The generated file contains:

- 20 replicates at `n_sub = 100`
- 20 replicates at `n_sub = 500`
- 3 classifiers
- 5 folds per classifier per replicate
- 600 total rows

The supplied replicate 1 at `n_sub = 100` is preserved, and the remaining results are generated by the script.

---

## Step 2: Compute the Four Statistics

After `results_extended.csv` has been generated, stay in the `Week_1/src` folder and run:

```bash
python compute_statistics.py
```

The script reads:

```text
Week_1/data/truth.csv
Week_1/data/results_extended.csv
```

and prints the results for both sample sizes.

---

## Step 3: Run the Edge-Case Test Suite

The statistics code was revised to generalize beyond 3 classifiers, detect ties, and validate the structure of each replicate before use, in response to feedback on the original submission. `test_edge_cases.py` proves this on small, hand-built synthetic datasets where the correct answer is known in advance.

Stay in the `Week_1/src` folder and run:

```bash
python test_edge_cases.py
```

Expected output ends with:

```text
17 passed, 0 failed
```

See `docs/RESPONSE_TO_FEEDBACK.md` for what each test proves and why.

# What Each File Does

### `truth.csv`

Contains the true AUC for each classifier.

| Classifier | True AUC |
|:--:|--:|
| c1 | 0.85 |
| c2 | 0.82 |
| c3 | 0.76 |

Therefore, c1 is the true best classifier.

### `results.csv`

Contains the supplied toy results for replicate 1 at `n_sub = 100`.

### `generate_results.py`

Generates the extended results dataset used for the Week 1 analysis.

### `results_extended.csv`

Contains the complete 600-row dataset used by the statistics code.

### `compute_statistics.py`

Computes:

- winner-correct rate
- mean Kendall's tau
- mean optimism
- power for c1 vs c2
- sign-error rate

for both `n_sub = 100` and `n_sub = 500`. Classifiers are read dynamically from `truth.csv` rather than hardcoded, so the code works for any number of classifiers. Every replicate is validated for missing classifiers, missing folds, duplicate folds, unexpected fold numbers, and unequal fold counts before its statistics are used, and ties (both observed and in truth) are explicitly detected and handled.

### `test_edge_cases.py`

Synthetic, hand-built tests proving the validation and tie-handling behaviour in `compute_statistics.py` actually works, since `truth.csv` and `results.csv` don't contain any of these cases themselves. Run it directly for a PASS/FAIL report against 17 checks.

### `Week_1_Hand_Calculations.pdf`

Contains the manual calculations for the required statistics and verification against the Python implementation.

### `Edge_Cases.pdf`

Contains the decisions and rules for handling edge cases.

### `RESPONSE_TO_FEEDBACK.md`

Maps each point of feedback received on the original submission to exactly what changed in the code and which test in `test_edge_cases.py` proves it.

# Data Format

The results data follows the required structure:

```text
dataset_id
protocol_id
n_sub
replicate_id
classifier_id
fold_id
auc
```

The truth data contains:

```text
dataset_id
classifier_id
true_auc
```

This toy dataset happens to contain 3 classifiers and 5 folds per classifier per replicate. The code itself does not assume this, `compute_statistics.py` reads the classifier list from `truth.csv` dynamically and has been tested with as many as 6 classifiers (see `test_edge_cases.py`).
